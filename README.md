# Brain Tumor Detection & Classification

This repository contains a machine learning framework designed to detect and classify brain tumors from medical imaging data (MRI). The goal is to provide a reliable automated tool to assist in early diagnosis and clinical decision-making.

---

## 🚀 Features
* **Image Preprocessing:** Grayscale conversion, noise reduction, and normalization.
* **Deep Learning Models:** Implementation of Convolutional Neural Networks (CNNs).
* **Data Augmentation:** Techniques to handle small datasets and prevent overfitting.
* **Visualization:** Heatmaps and Grad-CAM to interpret model predictions.
